# Walk-in Count

Restaurant inventory counting: snap shelf photos or a walk-through video, or say what changed, and the AI keeps on-hand counts and par levels up to date.

- `index.html`: the app (one file, served by GitHub Pages).
- `tools/source.html`: the app source.
- `tools/build_standalone.py`: rebuilds `index.html` from the source (`python3 tools/build_standalone.py`).

The AI key is entered in the app's Settings and stays on the device. Inventory is stored in the browser.
